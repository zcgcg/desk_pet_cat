### 改动内容
- 新增 `autostart.py`：Windows 开机自启动管理脚本（纯标准库 winreg，无第三方依赖）
  - 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，无需管理员权限
  - 用 `pythonw.exe` + main.py 绝对路径静默启动，开机不弹黑框
  - 命令：`python autostart.py enable|disable|status`
  - `sys.executable` 自适应：用哪个解释器跑，就写哪个解释器的 pythonw
- `main.py` 修改（4 处，均不改变原有逻辑）：
  1. 新增 `from PyQt6.QtNetwork import QLocalServer, QLocalSocket`
  2. 新增 `_ensure_single_instance()`：QLocalServer 命名管道单实例互斥（SalaryCat.SingleInstance），防止开机自启与手动启动撞车出现两只猫
  3. `main()` 开头调用单实例检查，重复实例直接 `return 0`
  4. `contextMenuEvent` 右键菜单新增「开机自启动」勾选项 + `_toggle_autostart()` 方法
- README.md / MANUAL.md 补充开机自启动说明
